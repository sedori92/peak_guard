# 피크가드 설치 안내 (관리자용)

파이썬이나 개발 도구를 설치하지 않고, **Docker Desktop(도커, 프로그램을 통째로 담아 실행하는 상자)** 하나로 피크가드를 켜는 방법입니다.
윈도우 보안 기능(스마트 앱 컨트롤)이 켜진 PC에서도 동작하도록, 피크가드는 상자 안(리눅스)에서 실행됩니다.

```
[피크가드 상자]  DB + 예측모델 + 서버   ← Docker Desktop 이 실행
      ↑
[브라우저]  http://localhost:8000          ← 관리자는 주소만 열면 됨
```

## 1. 처음 한 번만 (약 1시간)

| 순서 | 할 일 | 비고 |
|---|---|---|
| 1 | **Docker Desktop 설치**: https://www.docker.com/products/docker-desktop → "Download for Windows" → 설치 → 컴퓨터 다시 시작 | 설치 중 "WSL 2 사용" 체크 그대로 두기. 무료(개인·교육·소규모 기업) |
| 2 | 시작 메뉴에서 **Docker Desktop** 실행 → 창 아래쪽에 **Engine running**(엔진 실행 중)이 보일 때까지 기다리기 | 로그인 창은 **Skip**(건너뛰기) 해도 됨 |
| 3 | **피크가드 설치 파일** 압축 풀기 (예: `문서\피크가드`) | 구글 드라이브 팀 폴더의 `피크가드_설치파일.zip`, 또는 GitHub → **Code → Download ZIP** |
| 4 | 기업 자료 넣기: 전력 CSV 8개 → `data\raw` 폴더, 기상청 ASOS CSV → `data\weather` 폴더 | 폴더가 없으면 시작 파일이 만들어 줌 |
| 5 | **`피크가드_시작.bat` 두 번 누르기** | 처음에는 프로그램 내려받기 + DB 구축 + 모델 학습으로 30분~1시간. 끝나면 브라우저가 저절로 열림 |

> 윈도우가 "PC 보호" 파란 창을 띄우면 **추가 정보 → 실행**을 누릅니다 (인터넷에서 받은 .bat 파일이라 한 번 묻는 것).
> 보안 기능 때문에 .bat 파일이 아예 막히면: 파일을 마우스 오른쪽 → **속성** → 아래쪽 **차단 해제** 체크 → 확인.
> 그래도 막히면 .bat 없이 직접 입력합니다 — 설치 폴더 주소창에 `cmd` 를 입력해 명령 프롬프트를 열고
> `docker compose up -d --build` 를 입력한 뒤, 몇십 분 뒤 브라우저에서 http://localhost:8000 을 엽니다.

## 2. 매일 쓰기

| 하고 싶은 일 | 방법 |
|---|---|
| 켜기 | Docker Desktop 실행 → `피크가드_시작.bat` 두 번 누르기 (1분 안에 브라우저가 열림) |
| 화면 보기 | 브라우저 주소창에 **http://localhost:8000** |
| 끄기 | `피크가드_중지.bat` (DB·모델·연락처는 그대로 남음) |
| 진행 상황·오류 보기 | `피크가드_기록보기.bat` |
| 새 전력 자료 넣기 | 화면 오른쪽 위 **[실시간 연결] → 파일 끌어다놓기**, 또는 CSV 를 `data\incoming` 폴더에 넣고 [실시간 연결] |
| 컴퓨터를 다시 켰을 때 | Docker Desktop 만 켜면 피크가드도 저절로 다시 켜짐 (Docker Desktop 톱니바퀴 → General → 'Start Docker Desktop when you sign in to your computer' 체크 시 로그인과 함께 자동) |
| Docker Desktop 창 | 최소화하거나 X 로 닫아도 계속 동작(작업 표시줄 고래 아이콘). 고래 아이콘 → Quit 하면 피크가드도 멈춤 |

## 3. 같은 사무실의 다른 PC 에서 보기

피크가드를 켠 PC 의 IP 주소(명령 프롬프트에서 `ipconfig` → IPv4 주소, 예: 192.168.0.15)를 확인해
다른 PC 브라우저에서 **http://192.168.0.15:8000** 을 엽니다. 윈도우 방화벽이 물으면 **허용**합니다.
다른 PC 에는 아무것도 설치하지 않습니다.

## 4. 폴더 안내

| 폴더 | 내용 | 주의 |
|---|---|---|
| `data\raw`, `data\weather` | 기업 전력·기상 CSV | 기업 자료 — 외부 공유 금지 |
| `data\incoming` | 새로 받은 CSV 를 넣는 곳 ([실시간 연결] 때 읽음) | |
| `state` | DB 파일 (측정값·예측·**입주자 연락처**) | 개인정보 포함 — 외부 공유 금지, 백업 권장 |
| `models` | 학습된 모델 | 지우면 다음 시작 때 다시 학습 (30분) |
| `reports` | 보고서·시연 파일 | |

## 5. 기업 시스템(MariaDB)에 연결할 때

설치 폴더에 `.env` 파일을 만들고 기업 DB 접속 정보를 적은 뒤 다시 시작합니다. 항목은 [INTEGRATION.md](INTEGRATION.md) 와 `.env.example` 을 봅니다.

## 6. 문제가 생기면

| 증상 | 해결 |
|---|---|
| "Docker Desktop 이 설치되어 있지 않거나 꺼져 있습니다" | Docker Desktop 을 켜고 **Engine running** 이 보인 뒤 다시 실행 |
| Docker Desktop 이 "WSL" 또는 "가상화" 오류를 냄 | 윈도우 업데이트 후 재시작. 계속되면 BIOS 에서 가상화(Virtualization) 켜기 — 전산 담당에게 문의 |
| 브라우저에 "연결할 수 없음" | 처음 시작이면 아직 학습 중일 수 있음 → `피크가드_기록보기.bat` 에서 "3/3 서버 시작" 이 나올 때까지 기다리기 |
| 학습을 처음부터 다시 하고 싶음 | 끄고 `models` 폴더 안 파일을 지운 뒤 다시 시작 |
| 자료를 처음부터 다시 넣고 싶음 | 끄고 `state` 폴더 안 파일을 지운 뒤 다시 시작 (연락처도 지워지니 주의) |

## 개발자용 (참고)

상자 정의: `Dockerfile`, `docker-compose.yml`, `docker/entrypoint.sh`.
직접 명령으로: `docker compose up -d --build` (켜기) · `docker compose stop` (끄기) · `docker compose logs -f` (기록).
파이썬으로 직접 실행하는 방법은 README 의 1번(실행)을 봅니다 (보안 정책이 강한 윈도우 PC 에서는 막힐 수 있음).
