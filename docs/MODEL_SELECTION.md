- 입력: 직전 수요·현재전력·전일/전주 같은 시각·시간·요일·공휴일 + 기온 평소 대비·1시간 변화

- 선정: 채널별 예측 후 합산 · Bi-LSTM
- 근거 ① 기업 목표: 기준모델(전일 동일시각) 대비 MAE 76.6% 개선 (목표 10% 이상) — MAE 0.619 kW
- 근거 ② 피크 경보: 실제 위험 39건 중 35건 사전 감지(재현율 90%), 헛경보 21건(정밀도 62%) — 재현율과 정밀도를 함께 본 F1 0.737로 후보 중 가장 높음
- 근거 ③ 위험을 기준의 95%부터 알려 후보 모델 모두 재현율이 높음. 재현율만 보면 채널별 합산 후 예측 · LightGBM(97%)가 가장 높지만 헛경보가 116건으로 많아, 관리자가 실제로 쓰기에는 헛경보가 적은 모델이 유리
- 참고: 기업 권장 방식(채널별 합산 후 예측) 안에서는 Bi-LSTM — 재현율 90%, 헛경보 30건, F1 0.673, MAE 0.676
