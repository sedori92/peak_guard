# 피크가드 기술문서

실증 전력데이터 기반 AI 전력 수요·피크 예측 및 에너지 절감 의사결정 지원 서비스 (유큐브 PROJECT_02, 식스센스 팀)

이 문서는 기업 과제 원문과 멘토링 답변(11.03 · 11.06 · 11.11 · 11.12)을 기준으로 구현한 내용을 정리합니다.
모델 성능 숫자와 선정 근거는 [MODEL_SELECTION.md](MODEL_SELECTION.md), 기업 시스템 연계는 [INTEGRATION.md](INTEGRATION.md) 를 봅니다.

## 2. 데이터와 전처리

### 2-1. 전력 (기업 제공 CSV)
- 열: 전력량계 ID, 채널 번호, 측정 시간, 현재 전력(kW), 누적 사용량(kWh), 수요 전력(kW)
- 8개 전력량계 · 96개 계측채널 (공용 62, 호실 34), 2026-06-29 ~ 11-02, 1,015,520행
- 2026-10-06 15:00 ~ 10-20 15:00 수집 중단 (통신회선 교체, 기업 답변) — 채우지 않음
- 건물 합계 = **96개 채널 수요전력 단순합** (분석용 잠정값, 한전 공식 최대수요전력·계약전력 기준 아님 — 기업 답변)
- 예측 대상 = 수요전력 (기업 답변: 기준모델과 AI 모델이 같은 수요전력 시계열 사용)

### 2-2. 정제 규칙
| 항목 | 처리 | 근거 |
|---|---|---|
| 측정 시각 | 15분 단위로 맞춤, 1분 이상 어긋난 행 제외 | 측정시간 정합 (3차 ②) |
| 중복 | 같은 채널·시각은 한 번만 저장 | DB 기본키 |
| **현재전력 음수** | **결측(NaN)** 으로 처리 (0·절댓값 변환 없음). 1시간(4칸) 이하 끊김만 보간, 더 긴 연속 구간은 **학습에서 제외**. 건물 합계 순간값은 그 칸의 수요전력을 대신 사용 | 추가 답변 5번 |
| 기록 | 음수 15,174건 (1.49%), 짧은 끊김 보간 361칸, 긴 결측 10,555칸(채널 1개, 학습 제외) | 추가 답변 5번 (전후 건수·비율 기록) |
| 수요전력 결측 | 정답에서는 결측 그대로, 입력에서는 1시간 이하만 보간 | 가짜 데이터 금지 |

학습 때마다 같은 기록이 `st_meta`(info.prep)에 저장되고 세 번째 화면 안내문에 표시됩니다.

### 2-3. 기상 (공개 데이터, 1차 답변 A6)
- 기상청 ASOS 광주(156) 분자료 → (t−15분, t] 평균, 15개 관측이 모두 있을 때만
- 기온·습도·풍속 → `weather_15m`
- 업데이트: `data/incoming/weather/*.csv`, 화면 [파일 끌어다놓기](자동 구분), `.env` 의 `WEATHER_API_URL`(설정 시) — [실시간 연결] 버튼과 함께 실행

## 3. 예측

### 3-1. 예측 범위와 판정 (1차 답변 C1~C3, 추가 답변 2·3번)
- 15분마다 다음 1시간 15분 × 4구간 예측 (건물 합계 + 활성 채널 61개)
- 피크 기준: 직전 30일 건물 합계 15분 수요전력의 95번째 백분위수 (화면에서 전월·당월·7~9월·12~2월로 바꿔 볼 수 있음, 기본값 최근 30일)
- **위험 판정 2단계**: 다음 1시간 예측 4칸 중 하나라도 **피크 기준 이상이면 '위험'**, 아니면 '정상' (예전 '주의'(기준의 95~100%)는 정상으로) (`config.ALERT_RATIO`)
- 최초 위험 예상 시각, 최대 예상 수요전력, 기준 대비 비율 표시
- 위험이면 예상 피크 시각 예측 kW 상위 5개 호실을 점검 대상으로 표시 (C4)

### 3-2. 입력 (예측 시점에 이미 알 수 있는 값만)
현재 수요전력, 현재전력 합계(순간값), 15분·30분·45분·1시간·2시간 전 수요, 15분 변화량, 최근 1시간 최대, 최근 4시간 평균, 전일·전주 같은 시각, 예측 시각(시간대), 요일, 주말·공휴일, 선행시간, **기온 평소 대비(최근 7일 평균과 차이)·기온 1시간 변화** (기온 그대로는 계절 착각으로 오차가 커져 제외, 습도는 분석에만), 채널, 채널 규모

미래 기온(예보)은 쓰지 않습니다. 기상 포함/미포함 성능은 세 번째 화면 ⑤에서 비교합니다.

### 3-3. 모델 (1차 답변 D1)
| 구분 | 내용 |
|---|---|
| 기준모델 | 전일 동일시각 (기업 지정) |
| 머신러닝 | LightGBM, XGBoost, Random Forest — 건물 합계 모델 1개 + 채널 공동 모델 1개, 선행시간을 입력으로 4구간 예측 |
| 딥러닝 | Bi-LSTM — 지난 6시간(24칸) 흐름 + 기상 + 시간 정보, 전체·채널 함께 학습 |
| 방식 | **채널별 합산 후 예측**(건물 합계를 바로 예측, 기업 권장) / **채널별 예측 후 합산**(채널 61개 예측을 같은 시각끼리 더함) |
| 기간 | 학습 ~2026-09-14 · 검증 09-15~10-06 · 시험 10-20 15:15~11-02 16:15 (시간순, 겹침 없음) |

### 3-4. 평가 (1차 답변 D1·D2, 과제 원문 세부 3·7)
- MAE(평균 절대 오차, 주 지표), RMSE(평균 제곱근 오차), MAPE(평균 절대 백분율 오차, 실측 1kW 미만 제외)
- 기업 목표: 기준모델 대비 MAE 10% 이상 개선
- 피크 경보: 실제 위험(실측 4칸 중 하나라도 기준 이상) vs 예측 위험(예측 4칸 중 하나라도 기준 이상) → 맞힘·놓침·헛경보, 재현율·정밀도·오분류율
- 예측시각과 실제 발생시각 오차, 조건별(평일·주말·근무시간·그 밖) 정확도
- 모든 모델을 같은 예측 시점(공통 표본)에서 비교

## 4. 분석 (실측만)
| 화면 | 내용 | 근거 |
|---|---|---|
| ② 최고관리자 보고서 | 일·주·월·연 피크 변동기록, 피크 시각 영향도 Top 10(건물 대비·호실 34개 대비), 평소 대비 증가 Top 10, 스프레드시트 | 과제 세부 4, 3차 ④ |
| ② 층별 배치도 · 영향도 | 피크 시각 호실별 실측, 평소 대비 증가를 채널별(전체) / 시간 기준(채널)으로 나눈 폭포 그래프 | 3차 ③ |
| ② 사용패턴 분석 | 요일×시간대, 월별, 피크 반복 시각, 기상 상관, 이상 사용패턴, 피크 전 2시간 패턴, 절감 필요 시간대·대상 | 과제 목표 1, 세부 2·4·5 |

호실 비중은 같은 15분 칸 기준으로 계산하며, 개별 호실 최대를 더하지 않습니다 (3차 ②). 비중은 사용 비중이며 인과 영향·요금 배분율과 다릅니다 (3차 ③).
