# 서비스 시나리오 기반 기능 테스트

기업 과제 원문 세부 7 "서비스 시나리오 기반 기능 테스트". 관리자가 실제로 하는 일을 순서대로 따라가며, 화면이 쓰는 API 결과가 기업 답변의 규칙대로 나오는지 자동으로 확인합니다.

- 실행: `python -m pytest tests/test_scenarios.py -v` (기능 단위 시험 `tests/test_smoke.py` 와 함께 `python run.py 7`)
