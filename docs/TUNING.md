# 하이퍼파라미터(모델 설정값) 비교

과제 원문 필요 기술 '학습·하이퍼파라미터 튜닝'. 선정 방식(채널 합산 후 예측, 건물 합계를 바로 예측)의 4개 모델을 대상으로,
학습기간(~2026-09-15 00:00)으로 학습하고 **검증기간(2026-09-15 00:00 ~ 2026-10-06 23:45, 예측 시점 2,108개) 건물 합계 MAE** 로 비교했습니다.
시험기간은 보지 않았습니다(시험 성능은 마지막 한 번만 측정). 실행: `python -m peakguard.tools.tune`

판단 규칙: 학습기간으로 학습, 검증기간 건물 합계 MAE 비교 (시험기간 미사용). 처음 설정보다 2% 이상 좋으면 교체.

맞힘·놓침·헛경보는 검증기간 최근 30일 기준 피크 위험(참고). ★ = 현재 적용 설정, 굵게 = 검증 MAE 가장 작음.

## 결과 정리

트리 3종은 처음 설정(잎 63개·깊이 7·잎 최소 표본 3)보다 단순한 설정에서 검증 MAE가 9~12% 줄었습니다. 학습기간(여름)에 지나치게 맞춘(과적합) 것을 줄인 효과로 보고, '채널 합산 후 예측'의 건물 직접 모델에 적용했습니다(채널 공동 모델은 학습 행이 많아 기존 값 유지). Bi-LSTM은 학습률 0.001이 1.3% 좋았지만 기준(2%)에 못 미치고 검증기간 피크 맞힘이 21건 → 18건으로 줄어 현재 설정(은닉 48, 학습률 0.002)을 유지했습니다. 설정을 바꾼 뒤 전체를 다시 학습하고 시험기간 성능을 한 번만 측정했습니다.
